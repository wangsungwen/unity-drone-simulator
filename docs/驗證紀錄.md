# Hugging Face 網頁版 0.1.0（2026-10-14）

獨立 Three.js / JavaScript 瀏覽器模擬器，附 Static Space YAML 與所有前端資產。本機 HTTP + Chrome 無介面驗收：3D 渲染、起飛、鍵盤移動、暫停／重置、課程及尺寸選單、說明對話框、兩指搖桿及釋放歸零、直向不橫向溢出通過；未出現 JavaScript pageerror。8 項模型測試通過，涵蓋三種 Mode、起降與高度保持、相對機頭運動、風及邊界、路線尺寸、連續停懸及定點降落。人工檢視桌面、手機橫向／直向與五邊航線截圖。

尚未部署至真實 Hugging Face Space，也未測試實體手機或 Safari。Unity WebGL 模組安裝被工具自動審核拒絕（未提供原因）；交付為獨立網頁版，非 Unity WebGL 匯出。網頁模型與 Unity 完整術科判定差異詳見 HuggingFaceSpace/README.md。
